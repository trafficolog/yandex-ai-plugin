# FABLE 5.1 PR C — Yandex Direct 2.0.0 Helper Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish the Direct 2.0.0 helper migration by removing argv secrets, bounding operational errors, adding sandbox support and transport metadata, and enforcing a service-local HTTP behavior contract without introducing a shared runtime package.

**Architecture:** Keep `yd_api.py` as the Direct-specific API façade but split reusable Direct-local HTTP mechanics into a focused `_http.py` so the CLI/client code no longer carries transport parsing/redaction/error-body concerns inline. Preserve the PR A approval envelope and include environment selection in its digest. Add repository-level behavioral HTTP tests that compare invariants across service-local clients without importing a root runtime dependency.

**Tech Stack:** Python 3.10+, stdlib `urllib`, `json`, `argparse`, `unittest`; official Yandex Direct production/sandbox endpoints verified during implementation.

**Spec:** `docs/superpowers/specs/2026-09-03-fable-5.1-remediation-design.md`

## Global Constraints

- Direct is already staged at `2.0.0` from PR A; this PR completes that unreleased major before any 2.0.0 tag is published.
- Preserve exact-operation approval binding from PR A, including production/sandbox environment in the digest.
- Remove normal CLI `--token`; use `YANDEX_DIRECT_TOKEN`.
- HTTP error body read is capped at 4096 bytes by default and decoded with `errors="replace"`.
- Expected operational CLI failures produce structured stderr JSON and nonzero exit without normal traceback.
- No automatic retry for consequential POST writes.
- Add injectable transport/opener for tests.
- Add strict supported-service validation based on current Direct v501 service list.
- Add sandbox via current official endpoint/path contract; do not infer by hostname substitution.
- Expose `RequestId`, `Units`, and relevant documented unit headers as separate transport metadata.
- No shared root HTTP package.

---

## File Structure

- Create `plugins/yandex-direct/scripts/_http.py` — Direct-local request execution, bounded HTTP errors, response metadata extraction, header redaction, injected opener.
- Modify `plugins/yandex-direct/scripts/yd_api.py` — CLI, environment selection, supported service validation, structured output/errors; consume `_http.py` and PR A `_approval.py`.
- Create `plugins/yandex-direct/tests/test_http.py`.
- Modify `plugins/yandex-direct/tests/test_yd_api.py`.
- Create/Modify root `tests/test_http_contracts.py` — behavioral invariants across Direct/Metrika/Webmaster/Wordstat/Search HTTP layers where interfaces permit.
- Modify Direct README/changelog/safety/API references RU/EN as required.
