# FABLE 5.1 PR A — Safety Enforcement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bind every consequential Direct, Metrika, and Webmaster execution to the exact secret-free operation preview approved by the user, while preserving read-only behavior and independent plugin installability.

**Architecture:** Each write-capable service plugin gets a tiny service-local `_approval.py` adapter implementing deterministic canonical JSON + SHA-256. Consequential transport boundaries emit `preview_id` and require `--execute --approve <preview_id>` before any network call. Metrika imports additionally bind SHA-256 of file bytes. Webmaster specialized builders remain pure request constructors; approval is enforced where the descriptor crosses the `yw_api.py` transport boundary.

**Tech Stack:** Python 3.10+, stdlib `hashlib`, `json`, `argparse`, `pathlib`, `unittest`.

**Spec:** `docs/superpowers/specs/2026-09-03-fable-5.1-remediation-design.md`

## Global Constraints

- Lifecycle remains `read → analyze → preview → explicit approval → write → verify`.
- Helpers enforce exact-operation integrity, not proof that a human approved in a prior conversation turn.
- Missing/mismatched approval errors never reveal the expected digest.
- Canonical JSON uses `sort_keys=True`, `separators=(",", ":")`, UTF-8, `ensure_ascii=False`.
- Tokens/API keys never enter canonical approval data.
- Direct digest binds environment, exact service URL, Direct API method, `Client-Login`, and request body.
- Metrika digest binds HTTP method, full URL/query, counter/action identifiers, body, and upload file SHA-256 where applicable.
- Webmaster digest binds API version, HTTP method, full URL/query, host/site/action identifiers, and body.
- Reads do not require approval.
- No shared root runtime package.
- Direct/Metrika/Webmaster are staged at `2.0.0`; no 2.0.0 tags are published until PR A, B, and C are merged and green.

- [ ] **Step 3: Implement identical service-local adapters**

```python
from __future__ import annotations

import hashlib
import json
from typing import Any, Mapping

ERROR = "execution requires approval of the exact preview; generate and show a fresh preview first"


def _canonical_json(envelope: Mapping[str, Any]) -> str:
    return json.dumps(envelope, sort_keys=True, separators=(",", ":"), ensure_ascii=False)


def preview_id(envelope: Mapping[str, Any]) -> str:
    return hashlib.sha256(_canonical_json(envelope).encode("utf-8")).hexdigest()


def require_approval(envelope: Mapping[str, Any], supplied: str | None) -> str:
    expected = preview_id(envelope)
    if not supplied or supplied != expected:
        raise ValueError(ERROR)
    return expected
```

```python
def sha256_file(path: Path) -> str:
    digest = hashlib.sha256()
    with Path(path).open("rb") as handle:
        for chunk in iter(lambda: handle.read(1024 * 1024), b""):
            digest.update(chunk)
    return digest.hexdigest()
```
