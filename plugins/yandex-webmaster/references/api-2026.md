# Yandex Webmaster API facts — verified 2026-09-01

Official API root: https://api.webmaster.yandex.net/
Documentation: https://yandex.ru/dev/webmaster/

Yandex currently advertises Webmaster API 4.1, but the documented surface is mixed: most established resources remain under `/v4/`, while newer resources such as priority Sitemap recrawl use `/v4.1/`. Do not globally rewrite all endpoints to 4.1.

## Authentication

Use `Authorization: OAuth <token>`. Bundled helpers read `YANDEX_WEBMASTER_TOKEN` and redact previews as `OAuth ***`.

Current OAuth setup documentation asks for `webmaster:hostinfo` and `webmaster:verify` permissions. Permission requirements can vary by resource; do not infer authorization from possession of a token alone.

Resolve `user_id` via `GET /v4/user`. Resolve hosts via `GET /v4/user/{user-id}/hosts` instead of asking the user for opaque IDs when live access can resolve them.

## Safety

Writes follow `read → analyze → preview → explicit approval → write → verify`. Recrawl/export operations may consume quota. Host/sitemap/feed deletion is destructive.
