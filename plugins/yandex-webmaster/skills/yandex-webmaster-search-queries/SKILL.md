# Search queries

Read `../../references/queries.md`. Use `scripts/yw_queries.py` to construct reproducible requests.

Popular queries are a top-N view; never label them complete coverage. Preserve date range, device, sort/order, offset, limit, regions and filters. Use Query Analytics when the question needs richer URL/query/region/statistic filtering.

When explaining changes, decompose impressions, clicks, CTR and position and compare equivalent periods. Do not invent causal certainty.
