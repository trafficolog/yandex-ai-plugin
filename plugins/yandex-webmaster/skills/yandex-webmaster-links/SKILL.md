# Links

Use the generic API helper for documented v4 link resources, including external samples and broken internal-link samples/history. This skill is read-only in plugin 1.0.0.

Prioritize recurring broken internal links and meaningful external-link changes, but distinguish Yandex samples from a complete crawler/link index when the endpoint is sample-based.
