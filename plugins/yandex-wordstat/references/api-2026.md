# Yandex Wordstat Cloud API baseline

Verified: 2026-09-02

Primary bundled backend: Yandex Cloud Search API Wordstat REST v2.

| Operation | Endpoint | Notes |
|---|---|---|
| GetTop | `POST /v2/wordstat/topRequests` | last 30 days; returns `totalCount`, `results`, `associations` |
| GetDynamics | `POST /v2/wordstat/dynamics` | historical time series; REST uses `fromDate`/`toDate` |
| GetRegionsDistribution | `POST /v2/wordstat/regions` | last 30 days; count/share/affinityIndex |
| GetRegionsTree | `POST /v2/wordstat/getRegionsTree` | recursive region tree; currently free |

GetTop constraints currently documented: phrase <= 400 chars, `numPhrases` 1..2000, <=100 regions, <=3 devices, and at most 20 returned associations. `folderId` maximum length is 50 characters when supplied. Because 20 is a result cap, receiving exactly 20 associations means association coverage may be truncated and downstream workflows must preserve that limitation.

The official legacy Wordstat API at `https://api.wordstat.yandex.net/v1` still exists, but the bundled Cloud adapter remains the primary backend.
