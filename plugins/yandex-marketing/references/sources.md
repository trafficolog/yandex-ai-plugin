# Sources and ownership

**Verified: 2026-09-02**

Cross-service methodology is defined by this plugin. Volatile service and API facts remain owned by the current references in sibling Yandex Direct, Metrika, Wordstat and Search plugins. This plugin does not copy their endpoint tables, authentication material, mutable attribution-model names, quotas, or other volatile platform constants.

Source contract baseline used by 1.0.0:
- Yandex Direct plugin 1.0.0 — paid campaign, criterion, query, spend and attributed outcome evidence.
- Yandex Metrika plugin 1.0.0 — sessions, business goals, ecommerce, attribution and data-quality evidence.
- Yandex Wordstat plugin 1.0.0 — external demand, trend and region evidence.
- Yandex Search plugin 1.0.0 — optional SERP/intent/competitor context only.
