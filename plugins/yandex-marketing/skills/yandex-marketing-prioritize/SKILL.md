# Marketing prioritization

Default prioritization is categorical and evidence-based: measurement/context risks before economic optimization, then mature KPI-compatible budget/performance findings, demand/query candidates, and lower-confidence landing/traffic hypotheses. Do not invent an opaque Marketing Score.

If the user supplies priorities or weights, disclose them. Delegated actions are preview-only: route budgets to yandex-direct-budget, query changes to yandex-direct-keywords, strategy work to yandex-direct-optimize, campaign creation to yandex-direct-create, and goal changes to yandex-metrika-goals. Consequential actions require explicit approval in the owning plugin.
