# Landing analysis

Join landings conservatively and retain query parameters by default. Separate observed query/ad/landing metrics from interpretations.

Possible outputs include LANDING_MISMATCH_HYPOTHESIS, QUERY_MISMATCH_HYPOTHESIS, TRAFFIC_QUALITY_HYPOTHESIS, or MEASUREMENT_RISK. Observational correlation is not causal proof. Validate intent, measurement, device and landing context before recommending campaign or page changes.
