# Attribution and comparability

Use the KPI fingerprint before comparing conversion economics. If material context differs, mark the comparison INCOMPARABLE rather than choosing a winner.

Source plugins own volatile attribution model names and current platform details; the cross-service layer must not freeze volatile attribution names as canonical truth. Preserve source-provided model identifiers and periods exactly enough to explain the comparison.
