# Search-query intelligence

Keep actual Direct search queries distinct from Wordstat statistical phrases. Join only by conservative normalized query keys and preserve both source roles.

Zero conversions after an arbitrary number of clicks is not an automatic negative keyword rule. Before SEARCH_TERM_EXCLUSION_REVIEW, require business-goal alignment, conversion maturity, spend context, and explicit evidence sufficiency. Expansion candidates must still be checked against targeting, negatives and business relevance.

Search SERP context is optional evidence for intent; it must not modify CPA or ROAS calculations.
