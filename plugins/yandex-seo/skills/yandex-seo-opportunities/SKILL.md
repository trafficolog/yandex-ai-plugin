# SEO opportunities

Keep Wordstat demand and Webmaster demand as separate source-specific metrics; never substitute one for the other. Combine available demand, visibility gaps, SERP evidence, conversion evidence and technical state into transparent findings rather than an opaque score. A strong opportunity states which services support it, what is missing, period/geography alignment and confidence. If the user supplies priority weights or ordering, show them explicitly instead of inventing universal SEO thresholds.
