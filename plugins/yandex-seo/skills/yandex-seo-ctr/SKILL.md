# CTR opportunities

Use Webmaster as the canonical source for query-level Yandex impressions, clicks and CTR. Compare against the site's own historical or comparable baseline, preserving device/period/region context where available. Never apply a universal rule such as “position 3 must exceed X% CTR”. A detected gap is DERIVED evidence, not proof of a title/snippet cause. Report missing baseline, top-N limitations and incompatible periods instead of manufacturing a benchmark.
