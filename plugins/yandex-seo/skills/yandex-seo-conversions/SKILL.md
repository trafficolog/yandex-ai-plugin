# Organic conversion analysis

Use Webmaster to describe impression-to-click visibility and Metrika to describe visit-to-goal or revenue behavior. Preserve Metrika sampling/data-lag quality metadata and compatible periods. When a visible query/cluster lands on a page whose organic conversion rate is below the site's own comparable baseline, describe possible landing or intent mismatch as a HYPOTHESIS, not an observed cause. Never infer conversion metrics that are absent from Metrika evidence.
