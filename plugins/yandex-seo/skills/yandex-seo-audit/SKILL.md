# Cross-service SEO audit

Build an evidence table before conclusions. Separate OBSERVED source facts, DERIVED calculations and HYPOTHESIS interpretations. Review coverage, period and geography alignment, then demand, Search clusters/SERP, Webmaster visibility/indexing, Metrika organic performance and technical blockers. Propagate all limitations including sampling, top-N coverage and bridge risk. Missing evidence is REVIEW or unavailable, not failure. End with a compact action plan; live writes are outside this skill.
