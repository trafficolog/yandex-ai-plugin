# Yandex SEO router

Detect source coverage first: Wordstat, Search, Webmaster and Metrika may be complete or partial. Select Discovery, Visibility, Performance, Full SEO, or explicitly report PARTIAL coverage. Build findings only from preserved evidence and label claims as OBSERVED, DERIVED or HYPOTHESIS. Never fail globally just because one source is absent; state unavailable analyses and limitations. This skill is read-only and routes any consequential action back to the owning service plugin.
