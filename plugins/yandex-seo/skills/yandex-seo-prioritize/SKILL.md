# Prioritize SEO findings

Do not emit an opaque “SEO Score” or silently multiply unrelated metrics. Rank findings using categorical evidence such as technical blocker, validated content gap, cannibalization candidate, CTR opportunity, conversion hypothesis and discovery candidate, while preserving confidence and limitations. If the user provides a priority order, mark the priority basis as user-provided. Delegated actions must contain the owning service, skill, target, reason and `requires_approval`; they remain previews only.
