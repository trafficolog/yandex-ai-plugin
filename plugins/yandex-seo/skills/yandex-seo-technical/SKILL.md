# Technical-impact correlation

Correlate Webmaster diagnostics/indexing evidence with demand, Search visibility and performance evidence without claiming automatic causality. A valuable page that is not indexed may become a technical blocker finding. If recrawl or sitemap work is appropriate, create only a delegated preview naming the Webmaster skill, target and reason; execution still requires the Webmaster plugin's own preview and explicit approval. Never perform the write from this cross-service plugin.
