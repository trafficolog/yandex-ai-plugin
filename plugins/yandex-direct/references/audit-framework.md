# Audit framework

Audit evidence, not checkboxes. Mark every check as PASS, ISSUE, REVIEW, or N/A and retain the evidence used.

## Domains

1. Measurement: Metrika linkage, goals, ecommerce/revenue, offline conversions where applicable, attribution consistency.
2. Economics: spend, conversion volume, CPA/CPO, revenue/ROAS or DRR when supplied, budget pace, conversion delay.
3. Query quality: search terms, irrelevant intent, duplicated routing, negatives, autotargeting performance.
4. Structure: campaign intent, EPK placement configuration, geo, schedules, naming, archived/zombie entities.
5. Ads/assets: moderation status, message-to-landing relevance, asset coverage, broken/redirecting URLs, tracking parameters.
6. Strategies: goal alignment, sufficient data, budget constraints, bid ceilings and strategy settings.
7. Placement/device/audience: search vs network performance, devices, demographics/audiences only where statistically useful.
8. Change risk: recent large edits, learning disruption, unexplained step changes.

## Scoring

A score is optional. If used, exclude N/A checks from the denominator and publish category weights. Never hide missing evidence behind a single grade.

## Thresholds

Prefer account targets and distributions over generic market benchmarks. A threshold should state its basis: business target, historical percentile, experiment result, or current platform requirement.
