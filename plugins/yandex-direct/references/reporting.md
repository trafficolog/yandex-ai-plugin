# Reporting guidance

Before interpreting performance, state:

- exact date range and comparison range;
- account currency and whether VAT is included;
- attribution model and selected Metrika goals when conversion metrics are used;
- whether revenue is available and reliable;
- search/network split if the decision depends on placement.

Useful derived metrics:

- CTR = clicks / impressions;
- CPC = cost / clicks;
- CVR = conversions / clicks;
- CPA = cost / conversions;
- ROAS = revenue / cost;
- DRR = cost / revenue;
- budget pace = actual spend / expected spend by elapsed time.

Do not rank low-volume entities only by CPA. Include spend, clicks, conversions, conversion delay, and uncertainty. Search-query analysis should separate keyword traffic and autotargeting where possible.
