# New campaign workflow

Default architecture for a new performance campaign is EPK unless the user's existing account or a current platform constraint requires another type.

1. Capture business objective, landing page, geo, budget, target action/value, restrictions, brand terms, and measurement status.
2. Validate measurement. If conversion optimization is requested without a trustworthy goal, stop strategy configuration and produce a measurement gap.
3. Build semantic hypotheses from product/service intent. Use Wordstat or another current source for frequency; never fabricate frequency/CPC.
4. Cluster by user intent and landing-page relevance, then decide Search / Network / mixed placement explicitly.
5. Design negative phrases and cross-routing only where groups/campaigns would otherwise compete for the same query intent.
6. Draft ad copy/assets within current platform limits and verify legal/moderation-sensitive claims from current sources.
7. Select strategy from objective and available data; do not use fixed “N conversions/week” folklore as an API requirement unless current Yandex docs say so.
8. Produce a preflight summary: structure, targets, budget, strategy, tracking, URLs, negatives, assets, known gaps.
9. Preview creation payloads.
10. After explicit approval, create entities but leave activation as a separate human-approved action.
