# Yandex Direct API facts — verified 2026-09-01

Use this file as a compact factual baseline. For fields or policy limits that may change, verify the linked official documentation before making a write request.

## API version

- Unified Performance Campaign / Единая перфоманс-кампания (ЕПК) uses `https://api.direct.yandex.com/json/v501/`.
- Current service endpoints such as `campaigns`, `keywords`, `negativekeywordsharedsets`, `changes`, and `reports` are available under `/json/v501/`.
- Do not hard-code `/json/v5/` for new EPK workflows.

Official docs:
- https://yandex.ru/dev/direct/doc/ru/campaigns/campaigns
- https://yandex.ru/dev/direct/doc/ru/reports
- https://yandex.ru/dev/direct/doc/ru/keywords/keywords
- https://yandex.ru/dev/direct/doc/ru/negativekeywordsharedsets/negativekeywordsharedsets

## Authentication and agency accounts

Send `Authorization: Bearer <OAuth token>`. For an agency managing a client, use `Client-Login` when the API method supports it. Never place tokens in skill text, git, generated reports, or chat output.

## Reports

- Reports endpoint: `https://api.direct.yandex.com/json/v501/reports`.
- Reports are TSV.
- `processingMode` may be `online`, `offline`, or `auto`.
- HTTP 201 means queued; HTTP 202 means still generating; wait for the response header `retryIn` and resend the **same request parameters**.
- `returnMoneyInMicros: false` returns report money in account currency with two decimal places. Without it, report money is in millionths.
- Monetary values in report **filters** still use millionths regardless of `returnMoneyInMicros`.

Official docs:
- https://yandex.ru/dev/direct/doc/ru/reports
- https://yandex.ru/dev/direct/doc/reports/mode.html
- https://yandex.ru/dev/direct/doc/ru/headers
- https://yandex.ru/dev/direct/doc/ru/money

## Keywords and autotargeting

The `Keywords` service operates on both keywords and autotargeting. Autotargeting is represented by the special keyword value `---autotargeting`. Do not assume autotargeting is equivalent to an ordinary broad-match keyword; audit and report it separately via `CriterionType=AUTOTARGETING` where relevant.

Official docs:
- https://yandex.ru/dev/direct/doc/ru/keywords/keywords
- https://yandex.ru/dev/direct/doc/ru/best-practice/auto-targeting

## Negative phrases

Negative phrases can be set at campaign/group level, via shared negative sets, and inside a keyword. `NegativeKeywordSharedSets` supports add/update/delete/get in v501. Shared sets are useful for governance, but cross-negative logic must be based on intended query routing rather than blindly subtracting every sibling group.

Official docs:
- https://yandex.ru/dev/direct/doc/ru/objects/negative-keywords
- https://yandex.ru/dev/direct/doc/ru/negativekeywordsharedsets/negativekeywordsharedsets

## IDs

Yandex object identifiers can exceed JavaScript's safe integer range in integrations. Preserve IDs as decimal strings in JavaScript/JSON transformations when there is any risk of 64-bit values being rounded. Python integers are arbitrary precision.
