# Yandex Metrika API facts — verified 2026-09-01

Official API root: https://yandex.ru/dev/metrika/ru/

## API families

Yandex documents four main families:

1. Management API — counters, goals, filters, access and related managed objects.
2. Data Import API — expenses, CRM data, calls, offline conversions, visitor parameters and related imports.
3. Reporting API — table, by-time, comparison, drilldown and comparison-drilldown reports.
4. Logs API — asynchronous non-aggregated visit/hit exports.

## Authentication

Use a Yandex OAuth token. API examples use `Authorization: OAuth <token>`. Never commit or print the token; local helper previews replace it with `OAuth ***`.

## Base URLs used by this plugin

- Management / Data Import / Logs: `https://api-metrika.yandex.net/management/v1/`
- Reporting: `https://api-metrika.yandex.net/stat/v1/`

## Current reporting quality metadata

When returned, preserve `sampled`, `sample_share`, `sample_size`, `sample_space`, `data_lag`, `contains_sensitive_data`, and `total_rows_rounded`.

## Attribution

Current report parameterization models relevant to the plugin: `cross_device_first`, `last`, `cross_device_last_significant`, `automatic`. See `attribution.md`.
