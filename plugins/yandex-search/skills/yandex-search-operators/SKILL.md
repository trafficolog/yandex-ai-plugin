# Search operators

Preserve the exact expression. Useful operators include `-`, `!`, `+`, quotes, OR, `site:`, `host:`, `url:`, `domain:`, `mime:`, `lang:` and `date:`. Operators change the result set; never normalize them away before retrieval.
