# SERP research

Define objective, queries, region/search type and top-K. Run `yandex-search-batch` cost preview first. Collect compatible FLAT XML snapshots. Then use competitors/rankings/clustering as needed. If demand weighting is required, join later with Wordstat instead of calling unweighted SERP presence demand or market share.
