# Web search

Resolve query, search type and region. Use XML for structured results. Prefer `GROUP_MODE_FLAT` for SEO work. Preserve query/search configuration in the result snapshot. For 1–5 interactive requests, sync is normally appropriate; use `yandex-search-batch` for larger workloads.
