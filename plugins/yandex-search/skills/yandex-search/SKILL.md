# Yandex Search router

Route to: `yandex-search-web`, `yandex-search-batch`, `yandex-search-serp`, `yandex-search-competitors`, `yandex-search-rankings`, `yandex-search-clustering`, `yandex-search-operators`, `yandex-search-research`, or `yandex-search-api`.

Keep Wordstat demand analysis in the Wordstat plugin. For human region names, Wordstat `GetRegionsTree` may resolve a numeric region ID when available; Search itself accepts the numeric ID and does not keep a static region map.
