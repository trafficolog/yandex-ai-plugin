# Yandex Search API baseline — verified 2026-09-01

Primary endpoints: `POST /v2/web/search` and `POST /v2/web/searchAsync` on `searchapi.api.cloud.yandex.net`. REST uses CamelCase fields. Classic text search supports `SEARCH_TYPE_RU/TR/COM/KK/BE/UZ`, XML or HTML output, relevance/time sorting, freshness windows, region, family/fix-typo controls, and FLAT/DEEP grouping. Up to 250 results per query; query text is limited to 400 characters and 40 words.
