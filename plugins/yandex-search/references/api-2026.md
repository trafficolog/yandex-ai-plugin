# Yandex Search API baseline

Verified: 2026-09-02

Primary endpoints: `POST /v2/web/search` and `POST /v2/web/searchAsync` on `searchapi.api.cloud.yandex.net`. REST uses CamelCase fields. Classic text search supports `SEARCH_TYPE_RU/TR/COM/KK/BE/UZ`, XML or HTML output, relevance/time sorting, freshness windows, region, family/fix-typo controls, and FLAT/DEEP grouping.

The documented search depth ceiling is 250 results per query. Bundled request/snapshot helpers enforce complete result windows: `requested_per_page = groups_on_page * docs_in_group`, `window_start = page * requested_per_page`, `window_end = window_start + requested_per_page` (exclusive). A window ending exactly at 250 is valid; a window with `window_start >= 250` or `window_end > 250` is rejected rather than assuming partial-page truncation. Query text is limited to 400 characters and 40 words.
